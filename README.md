## Sistema de Control de Calificaciones



 Nombre: Xiomeiri Esther De La Cruz Berroa

Matrícula: 2025/2997

Lenguaje utilizado: C++

# 1. Descripción del programa

Este programa permite registrar y controlar las calificaciones de los estudiantes de un centro educativo. Solicita los datos de cada estudiante, calcula sus promedios y determina si está aprobado o reprobado. También presenta un resumen general del grupo e identifica al estudiante con el promedio más alto.

# 2. Datos de entrada

El programa solicita los siguientes datos:

Cantidad de estudiantes que se van a procesar.

Nombre de cada estudiante.

Cuatro calificaciones por estudiante, con valores entre 0 y 100.

Respuesta para indicar si se desea procesar otro grupo (s/n).

# 3. Proceso

El programa valida que la cantidad de estudiantes sea mayor que cero y que cada calificación esté dentro del rango permitido. Luego suma las cuatro notas, calcula el promedio individual y determina si el estudiante aprobó o reprobó.

Al finalizar, calcula el promedio general del grupo, cuenta los estudiantes aprobados y reprobados e identifica al estudiante con el promedio más alto y cierra con la pregunta si desea crear otro grupo de estudiantes.



# 4. Datos de salida

El programa muestra:

Promedio de cada estudiante.

Estado de cada estudiante: aprobado o reprobado.

Cantidad total de aprobados y reprobados.

Promedio general del grupo.

Nombre del estudiante con el promedio más alto y su calificación promedio.

# 5. Uso de los bucles

En el desarrollo del programa se utilizaron tres tipos de bucles:

Bucle for: Se utiliza para recorrer la cantidad de estudiantes y para solicitar las cuatro calificaciones de cada uno. Se eligió porque conocemos cuántas veces debe repetirse cada proceso.

Bucle while: Se utiliza para validar la cantidad de estudiantes y las calificaciones. Permite repetir la solicitud mientras el dato ingresado no cumpla con las condiciones establecidas.

Bucle do-while: Se utiliza al final del programa para permitir que se procese otro grupo de estudiantes. Se eligió porque primero debe ejecutarse el programa y luego preguntar si se desea repetir.
