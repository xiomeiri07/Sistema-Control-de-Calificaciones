# Sistema de Control de Calificaciones

## Descripción
Programa desarrollado en C++ para controlar las calificaciones de los estudiantes de un centro educativo.

## Funcionalidades
- Registrar la cantidad de estudiantes.
- Solicitar el nombre de cada estudiante.
- Ingresar cuatro calificaciones.
- Validar las calificaciones entre 0 y 100.
- Calcular el promedio de cada estudiante.
- Determinar si está aprobado o reprobado.
- Mostrar el resumen general del grupo.
- Identificar al estudiante con el promedio más alto.
- Permitir procesar otro grupo.

## Lenguaje utilizado
C++
